# Between Worlds — A Cosmic Journey

A single-page interactive Three.js experience.

## Run it
Because this uses JavaScript ES modules, open it through a local web server rather than `file://`.

### Quick option
- Upload `index.html` to GitHub Pages, Netlify, or another static host.
- Or run a local server in this folder:
  - `python -m http.server 8000`
  - Open `http://localhost:8000`

## Controls
- **Yes** starts the cosmic journey.
- **No** moves away from the pointer for the first five attempts, then lets the visitor choose the rainy/melancholy scene.
- **Continue** moves through Saturn, the solar system, and the Milky Way.
- In the Saturn scene, click Saturn or its rings to reveal the solar system.
- In the solar-system scene, click the starfield to reveal the Milky Way.
- **Start again** resets the experience.

Three.js is loaded from jsDelivr and fonts from Google Fonts, so an internet connection is needed.
